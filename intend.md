# aether-snake

## Intent

A text-based adventure game where players explore mystical locations, collect items, and uncover the mystery of the Aether Snake.

## Features

- Explore multiple interconnected locations (forest, shrine, ruins)
- Collect items and manage inventory
- Navigate with directional commands (north, south, east, west)
- Simple command interface

## How to Play

```bash
python game.py
```

Commands:
- `go <direction>` - Move to a new location
- `take <item>` - Collect items
- `inventory` - View your items
- `look` - Describe current location
- `help` - Show all commands
- `quit` - Exit game
